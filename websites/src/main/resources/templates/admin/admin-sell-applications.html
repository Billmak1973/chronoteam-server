若您已有心儀的門店或希望提前預約實物鑑定與面交時間，請填寫以下資訊。

    申請狀態與鑑定資訊

    確認認領此訂單？

    您即將認領此訂單並成為主要負責人。
    點擊「確定」將保存變更並成為操作人，點擊「取消」將放棄保存並關閉視窗。

    確認將此申請入庫？

    此操作將把商品正式計入門店庫存，
    並自動更新門店每日收購財務報表。
