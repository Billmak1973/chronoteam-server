當訂單未達到免郵門檻時，將向顧客收取此固定運費。
例如填寫 30000，則顧客訂單總額滿 3 萬即可自動免除快遞費。
選擇顧客下單後的默認配送策略。若選擇「無配送模式」，結帳時將隱藏所有快遞選項。
所有配送模式共用的每日截單時間。超過此時間下單，將順延至下一個配送週期。
截单日与送货日的间隔天数：
• -1：提前一天截单
• 0 ：当天截单
請至少選擇一天。系統會自動結合「全局截單時間」計算下一個符合條件的配送日。
當前選擇的配送日為連續日子，系統將按照「整體模式」計算配送週期。
獨立模式範例：若設定提前 2 天截單，則 週四前下單可選週六配送， 週五前下單可選週日配送。
當選擇「自定義天數」時生效，表示下單後 N 天送達。
顾客收货后可无条件申请退货的天数（0 表示不支持退货）。
顾客收货后可无条件申请换货的天数（0 表示不支持换货）。
